# CITRUS

**C**omplete **I**nner-membrane **T**earing by **R**emoving **U**nder **S**pine

## 背景

柑橘の薄皮と果肉は、房の「背」の部分で最も強く結合している。この部分で薄皮と果肉をうまく分離できないことにより、薄皮に苦みを持つ柑橘類(甘夏、八朔、文旦、グレープフルーツなど)は剥くのも食べるのも敬遠されがちである。しかし、薄皮と果肉をうまく分離してきれいに果肉だけを残すことができれば、これらは非常においしい果物なのである。非常にもったいない。

## 既存の剥き方

* [https://delishkitchen.tv/recipes/302424020828029221](https://delishkitchen.tv/recipes/302424020828029221)

**パターンA：スタンダードな手順**

1. 外皮を剥く
2. 房に分ける
3. 薄皮を剥く

* **欠点：** 背の結合が剥がれず、薄皮が残って苦くなる。

**パターンB：外皮ごと削る手順**

1. 外皮を剥く
2. 外皮を剥く際に背中の薄皮ごと剥く
3. 房に分けながら薄皮を剥く

* **欠点：** 汁で水浸しになる。不必要に果肉が削られてもったいない。剥けた果肉が美しさに欠ける。

## 甘夏・八朔の薄皮を綺麗に剥く手順

薄皮と果肉を結合している「背中の繊維」を効率的に外すための手順である。

1. **外皮を剥き、房に分ける**
まずは通常通り外皮を除去し、一房ずつに分離させる。
2. **腹側（種側）を切り落とす**
房の内側の直線部分を数ミリ切り落とす。
3. **背中に縦に1本ハサミで切り込みを入れる**
房の背中の真ん中に縦方向に切り込みを入れる。
4. **背中の切り込みから外側に向かって剥く**
背中に入れた切り込みを起点とし、繊維の方向（背の真ん中から外側）に反対に向く形で薄皮を剥がす。
5. **果肉を取り出す**
繊維の結合を逆方向に攻略することで、苦い薄皮が果肉に残らない。

### 用語解説

* **外皮**・・・柑橘の最も外側にある厚い皮。
* **薄皮**・・・果肉を包んでいる膜（じょうのう膜）。苦みの原因となる。
* **果肉**・・・薄皮の中に詰まっている、実際に食べる粒状の部分。
* **房の背中**・・・房の膨らんでいる外側の部分。薄皮と果肉の結合が最も強い。
* **房の腹**・・・房の内側の直線部分。種が位置する側。
* **房の縦方向**・・・房の上下（ヘタから底まで）を結ぶ軸の方向。
