## 甘夏・八朔の薄皮を綺麗に剥く手順

薄皮と果肉を結合している「背中の繊維」を効率的に外すための手順です。

1. **外皮を剥き、房に分ける**
2. **腹側（種側）を切り落とす**
房の内側の直線部分を切り落とす。
3. **背中に縦に1本ハサミで切り込みを入れる**
房の外側のカーブ（背）の頂点に沿って、縦に切り込みを入れる。
4. **背中の切り込みから外側に向かって剥く**
背中に入れた切り込みを起点とし、繊維の方向（背の真ん中から外側）に反対に向く形で剥がす。
5. **果肉を取り出す**
繊維の結合を逆方向に攻略することで、苦い薄皮が果肉に残ることなく、完全につるんと分離する。


---

### GitHub用解説（ロジックの補足）

> **技術的背景**
> 柑橘の薄皮と果肉は、房の「背」の部分で最も強く結合しています。この結合（繊維）の向きは背の中心から外側へ向かっています。
> 腹側から指を入れ、この背中の接合部を「縦方向」に直接剥がすことで、繊維の抵抗を最小限に抑えて剥くことが可能になります。
