## 甘夏・八朔の薄皮を綺麗に剥く最適化手順

薄皮と果肉を結合している「背中の繊維」を効率的に外すための手順です。

### 手順

1. **腹側（種側）に切り込みを入れる**
房の内側の直線部分を、キッチンバサミ等で端から端まで薄く切り落とします。
2. **腹側の切り口から指を入れる**
切り落とした部分から指を入れ、左右の薄皮を少し広げます。
3. **背中の接合部を縦方向に剥く**
背中の薄皮がつながっている部分（繊維の起点）に対し、**縦方向にくるっと**指を滑らせます。
4. **繊維を外して果肉を取り出す**
背中側の繊維を縦になぞるように外すことで、果肉を崩さず、薄皮から完全につるんと分離させることができます。

---

### GitHub用解説（ロジックの補足）

> **技術的背景**
> 柑橘の薄皮と果肉は、房の「背」の部分で最も強く結合しています。この結合（繊維）の向きは背の中心から外側へ向かっています。
> 腹側から指を入れ、この背中の接合部を「縦方向」に直接剥がすことで、繊維の抵抗を最小限に抑えて剥くことが可能になります。
