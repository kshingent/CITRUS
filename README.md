## 背景

柑橘の薄皮と果肉は、房の「背」の部分で最も強く結合している。この部分で薄皮と果肉をうまく分離できないことにより、薄皮に苦みを持つ柑橘類（甘夏、八朔、文旦、グレープフルーツなど）は剥くのも食べるのも敬遠されがちである。しかし、薄皮と果肉をうまく分離してきれいに果肉だけを残すことができれば、これらは非常においしい果物なのである。非常にもったいない。

## 既存の剥き方の限界

### 1. 腹から剥く標準的な手法

1. 外皮を剥く
2. 房に分ける
3. 薄皮を剥く

* **欠点：** 背の部分に薄皮が残りやすく、食べた際に強い苦みが残る。

### 2. 外皮ごと背を削ぎ落とす手法

1. 外皮を剥く
2. 外皮を剥く際に背中の薄皮ごと剥く
3. 房に分けながら薄皮を剥く

* **欠点：** 汁で水浸しになる。不必要に果肉が削られてもったいない。剥けた果肉が美しさに欠ける。

## 甘夏・八朔の薄皮を綺麗に剥く手順：CITRUS法

薄皮と果肉を結合している「背中の繊維」を効率的に外すための最適化された手順である。

1. **外皮を剥き、房に分ける**
まずは通常通り外来を剥き、一房ずつに分離させる。
2. **腹側（種側）を切り落とす**
房の内側の直線部分を数ミリ切り落とす。これにより、薄皮の袋構造を解体する準備が整う。
3. **背中に縦に1本ハサミで切り込みを入れる**
房の背中の真ん中に、縦方向に切り込みを入れる。
4. **背中の切り込みから外側に向かって剥く**
背中に入れた切り込みを起点とし、繊維の結合方向（背の真ん中から左右）に対して逆らう形で薄皮を剥がす。
5. **果肉を取り出す**
繊維の結合を「背」から攻略することで、苦い薄皮を一切果肉に残さず、完璧な状態で取り出すことが可能となる。

### 用語解説

* **外皮** ・・・ 柑橘の最も外側の厚い皮。黄色い表皮と白い綿状の部分。
* **薄皮** ・・・ 果肉を包んでいる膜（じょうのう膜）。甘夏等では苦みの元となる。
* **果肉** ・・・ 実際に食する粒状の組織（砂じょう）。
* **房の背中** ・・・ 房の外側の曲線部分。外皮と接していた面であり、結合が最も強固な部位。
* **房の腹** ・・・ 房の内側の直線部分。種が存在し、薄皮が合流する箇所。
* **房の縦方向** ・・・ ヘタから底へ向かう軸の方向。切り込みを入れるべき基準線。
